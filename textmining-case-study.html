Project Overview

This project applies a full NLP pipeline to a Wikipedia article on Key Events of the 20th Century. The goal: move from raw web data to a structured, visual representation of which countries were most historically connected — and how their co-occurrence patterns map to real geopolitical alliances and conflicts.

Business question: Which countries were most frequently co-mentioned in 20th century historical events, and does their relationship structure reflect the actual alliances and conflicts of the era?

Phase 1 — Web Scraping

Selenium with ChromeDriver (headless mode) programmatically scraped the full body text of the Wikipedia article. The raw output included navigation elements — menus, edit links, tool labels — that would corrupt NER results by introducing irrelevant named entities.

options = Options()
options.add_argument("--headless")
driver = webdriver.Chrome(executable_path=str(driver_path), options=options)
driver.get("https://en.wikipedia.org/wiki/Key_events_of_the_20th_century")
page_text = driver.find_element(By.TAG_NAME, "body").text
driver.quit()

# Line-by-line cleaning — remove navigation artifacts
bad_starts = ("Jump to content", "Main menu", "Search", "Tools", "Edit", "View history")
clean_lines = [l.strip() for l in page_text.splitlines()
               if l.strip() and not l.strip().startswith(bad_starts)]
clean_text = "\n".join(clean_lines)

Key Insight — Cleaning matters more than the model

Raw scraped text contained Wikipedia chrome (menus, edit links, tool labels) that NER would mis-classify as locations. Filtering out these patterns before NER produced the largest single accuracy gain in the pipeline.

Phase 3 — Named Entity Recognition

spaCy's en_core_web_sm model extracted geopolitical entities (GPE label). For each sentence, all unique GPE pairs were captured as candidate co-occurrence edges. An alias dictionary normalized variants (e.g., UK / Britain / U.K. → United Kingdom) before edge construction to prevent the same entity appearing as multiple nodes.

Key Insight — Alias normalization prevents node duplication

Without alias mapping, 'UK', 'Britain', and 'United Kingdom' become three different nodes in the graph, splitting the country's true connectivity. A custom alias dictionary collapses these into a single canonical node before network construction.

Phase 4 — Network Construction & Community Detection

An undirected NetworkX graph was built from the GPE pairs: 21 nodes, 53 edges, density 0.252, clustering coefficient 0.552. The Leiden algorithm (via cdlib) detected four communities that mirror real 20th-century alliance structures.

Key Insight — Quantitative method, qualitative validation

The communities detected by the Leiden algorithm — without any historical priors — match well-known 20th-century alliance structures. This is strong validation that NLP-derived networks can recover real-world geopolitical structure from unstructured text.

Key Findings

Finding 1 — Germany sits at the structural center.

Germany scores highest on degree, closeness, and betweenness centrality — consistent with its central role across both World Wars and Cold War history.

Finding 2 — Detected communities match real-world alliance structures.

The four Leiden communities map cleanly onto recognized 20th-century geopolitical groupings, validating the pipeline against historical knowledge.

Finding 3 — Cleaning impact dominates model choice.

Removing Wikipedia navigation artifacts before NER produced larger accuracy gains than swapping NLP models — confirming that data quality leads, not model selection.

Finding 4 — Alias normalization is essential for entity networks.

Without canonical aliasing, the same country appears as multiple nodes and the network's true structure is fragmented. Aliasing is a non-optional preprocessing step.
